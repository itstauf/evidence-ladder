# operating-rules.md

**Regenerated, not hand-edited.** This file is a digest. The synthesis skill rebuilds it
from every `suggest` and `auto-apply` entry in `learnings.md` and in each file under
`substrates/`, grouped by tag. Skills read this file instead of the whole learnings file,
so a skill that drafts a proposal reads `[SALES]` and `[PRICING]` and nothing else.

Do not edit it by hand. A new belief enters as an entry in `learnings.md` (or a substrate)
at `watch` and earns its way here. If you hand-edit this file, the next synthesis run will
stop and ask before it overwrites you.

---

## What lands here

| Tier | In this digest? | How a skill applies it |
|---|---|---|
| `auto-apply` | yes | Binding, after the context cue is checked against the current situation |
| `suggest` | yes | Applied, and the output says `(under review)` next to it |
| `watch` | no | Lives only in its source file. Never applied. |

Every rule carries its context cue. A rule without a cue is a bug.

---

## Rule format

```
### {Short rule title} | tier: `suggest` | tags: [TAG] [TAG]

**Rule:** What to do or not do, as an instruction.
**Context cue:** When this binds. When it does not.
**Sources:** N distinct. Earned in: `learnings.md` > {entry title} (or `substrates/{file}.md`)
**Last changed:** YYYY-MM-DD (promoted | demoted | regenerated)
```
