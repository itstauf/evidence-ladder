# Changelog

First public release.

- `learnings.template.md`: ladder table, source definition, tags, entry format, empty Growth Log.
- `operating-rules.template.md`: regenerated digest grouped by tag.
- Claude Code skills: `synthesize-learnings` and `log-observation`.

  objections, delivery process. Each shows every tier and one demotion.

  entry going up the ladder and back down.
- `docs/`: what counts as a source, the four honesty rules, choosing substrates (with a
  guided setup prompt).
- `prompts/project-instructions.md` for Claude Projects and ChatGPT Projects; `AGENTS.md`.
